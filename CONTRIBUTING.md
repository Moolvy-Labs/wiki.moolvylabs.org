# Contributing to MoolvyLabs Wiki 🚀

Welcome! Thank you for wanting to improve the official knowledge base of **MoolvyLabs**. This repository serves as the central hub for all our wiki pages. 

To maintain high-quality documentation, please follow these guidelines when creating or modifying wiki pages.

---

## 📌 Wiki Contribution Rules

### 1. AI-Generated Content. Human Content 🤖
* **Human content is preferred!** If you wrote the text yourself without any assistance, you **do not need** to mention anything. Just submit your work.
* If you create or modify a wiki page using **AI tools**, you **must explicitly state which AI** was used at the very bottom of the page (e.g., *"Assisted by ChatGPT"*).
* **Important:** You are fully responsible for the content you submit. If the AI generates errors, incorrect information, or outdated facts, the blame lies solely with the contributor. Always double-check AI outputs before saving.

### 2. Linking Internal Projects 🔗
* If the wiki page is related to any of our internal MoolvyLabs projects, services, or tools, you **must include official links** to those services.
* This ensures that anyone looking for information can immediately access the live service.
* **Warning:** Submissions that fail to include these necessary official links **may be rejected** by the maintainers.

### 3. No Plagiarism (Original Content Only) 🚫
* Do not copy and paste text directly from other websites, documentation, or blogs. 
* All information must be written in your own words or properly cited if you are quoting an official source.

### 4. Keep Information Up-to-Date ⏳
* If an internal service or project updates its features, please edit the existing wiki page to reflect the changes instead of creating a duplicate page. 

### 5. Clear Formatting & Structure 📑
* Use proper Markdown syntax (headings `#`, bullet points `*`, and code blocks ` ``` `) to keep pages neat, scannable, and readable.
* Ensure all links are active and working before submitting your changes.

---

Thank you for helping us grow the MoolvyLabs community! If you have any questions, feel free to open an issue.
